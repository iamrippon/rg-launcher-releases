## 2. Description of the Software

RG Launcher is an independent utility software engineered for personal computers. Its verified features include:
- Managing, isolating, and launching Minecraft: Java Edition game clients;
- Fetching official version manifests, client JARs, libraries, and assets directly from Mojang/Microsoft servers;
- Installing and managing community-developed mod loaders (including Fabric, Quilt, NeoForge, and Minecraft Forge);
- Browsing, searching, and downloading community mods, resource packs, shaders, and modpacks from third-party platforms (**Modrinth** and **CurseForge**);
- Managing and operating local dedicated Minecraft server instances;
- In-game HUD overlay synchronization via the bundled companion mod (`rg-companion.jar`);
- Optional local network discovery and port-tunneling utilities (`playit.gg`, `ngrok`) for cooperative multiplayer hosting;
- Automatic and manual software update verification via our public GitHub distribution repository.
